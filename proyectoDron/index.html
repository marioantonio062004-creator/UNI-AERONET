SISTEMA DE MONITOREO AÉREO

Plataforma web desarrollada para la visualización y supervisión de una transmisión de video en tiempo real proveniente de un vehículo aéreo no tripulado (UAV). El proyecto integra captura de video, redes de comunicación y servicios web para permitir que la señal pueda ser recibida y visualizada desde diferentes dispositivos conectados a la red.

NUESTRO PROYECTO

Tecnología, redes y transmisión

UNI AeroNet es un proyecto académico orientado al desarrollo de una plataforma para la recepción y visualización de video obtenido mediante un vehículo aéreo no tripulado.

El sistema combina tecnologías de captura de video, comunicaciones de red y desarrollo web, creando una arquitectura capaz de transportar la información desde el sistema aéreo hasta una interfaz accesible para los usuarios.

El proyecto busca demostrar cómo diferentes áreas de la ingeniería pueden integrarse para construir una solución de monitoreo y transmisión basada en tecnologías de redes.

ARQUITECTURA DEL SISTEMA

Componentes del proyecto

El sistema integra diferentes componentes que trabajan conjuntamente para capturar, transportar y visualizar la señal de video obtenida desde el vehículo aéreo.

🚁

Captura aérea

El dron incorpora una cámara encargada de obtener el video durante el vuelo y generar la señal que será transmitida.

📡

Comunicación

La infraestructura de red permite transportar la información de video desde el sistema aéreo hasta los servicios encargados de distribuirla.

🌐

Plataforma web

La interfaz permite visualizar la transmisión y consultar información relacionada con el proyecto y su funcionamiento.

RECURSOS RELACIONADOS

Conexión con UNI AeroNet

Los recursos presentados en esta sección están relacionados con las diferentes etapas que conforman UNI AeroNet. La construcción del sistema aéreo, la comunicación inalámbrica, la transmisión de datos y el desarrollo de la plataforma web forman parte de una misma arquitectura orientada al monitoreo y transmisión de información desde un sistema aéreo.

Estos materiales funcionan como referencias técnicas y educativas para comprender algunas de las tecnologías utilizadas o relacionadas con el desarrollo del proyecto.
